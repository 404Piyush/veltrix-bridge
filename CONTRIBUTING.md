# Contributing

Thanks for contributing to Veltrix Bridge.

## Development Setup

```bash
npm install
npm run dev
```

## Quality Gates

Before opening a PR:

```bash
npm run lint
npm run build
```

## Pull Request Guidelines

- Keep changes focused and scoped.
- Include screenshots for UI changes.
- Describe behavior changes and expected user impact.
- Link related issue(s) when applicable.

## Commit Style

Use clear, technical commit messages:

- `feat: add withdrawal lifecycle status panel`
- `fix: handle wallet switch error on L2`
- `refactor: simplify bridge status state updates`
